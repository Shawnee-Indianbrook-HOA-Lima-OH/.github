# Indianbrook HOA

This organization hosts source code, version control, and automated deployments for the Homeowners Association website and related web resources.

---

### Purpose

- **Source Control**: Managing the codebase and templates for the community website.
- **Automation**: CI/CD workflows for building and deploying public-facing pages.
- **Technical Maintenance**: Tracking website updates, bug fixes, and maintenance tasks.

> **Notice**: This organization is intended solely for software maintenance and website hosting. For resident services or official association business, please use established HOA communication channels.
